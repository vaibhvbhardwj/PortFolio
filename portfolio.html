AI Project
Swasthya Sathi

Swasthya Sathi is a healthcare-oriented AI platform deployed through AWS, built around safe patient assistance, structured health workflows, and human-reviewed medical communication.

System Modules
  • AI Lab Report Analyzer with abnormal value highlighting and patient-friendly explanations.
  • Doctor-in-the-loop AI chat with human approval before final medical response.
  • Medication tracker with dosage, frequency, notes, and reminder notifications.
  • 1:1 doctor consultation scheduling with verified doctors and auto pricing logic.
  • Notification system for reminders, updates, unread badges, and timestamped events.
  • JWT-protected profile management with password update support.
Architecture

Frontend: HTML5, CSS3, Vanilla JavaScript hosted on Amazon S3.

Backend: Node.js, Express.js, JWT auth, bcryptjs, hosted on Amazon EC2.

AI Layer: Amazon Bedrock with Claude 3 Sonnet and Claude 3 Haiku.

Database: DynamoDB with users, doctors, consultations, notifications, and medications tables.

AWS: EC2, S3, DynamoDB, Bedrock, IAM, CloudWatch.

Safety Guardrails
  • No diagnosis generation.
  • No prescription advice.
  • No medication stopping recommendation.
  • Mandatory medical safety disclaimer.

AI Project
AI-Powered Research Assistant

AI-Powered Research Assistant is a lightweight HTTP API and chat-style assistant that answers user questions in real time using Google ADK, Gemini, and a custom Wikipedia search tool for better factual grounding.

Core Capabilities
  • Answers user questions in real time through a lightweight HTTP API.
  • Uses Google ADK for agent structure and orchestration.
  • Integrates Gemini for intelligent response generation.
  • Enhances answers with a custom Wikipedia search tool for factual accuracy.
  • Accessible through a chat-style web interface.
Deployment & Architecture

API Layer: HTTP-based service for real-time question answering.

Agent Framework: Google ADK for orchestration and agent flow design.

Model: Gemini for response generation.

Retrieval Tool: Custom Wikipedia search tool for better context and factual support.

Hosting: Deployed on Cloud Run as a scalable web service.
